# data/

**Aucune donnée expérimentale n'existe.**

Aucun test physique n'a été réalisé : pas de mesures de banc, pas de séries de terrain, pas de résultats. Les seuls jeux de données ayant servi aux scripts d'`analysis/` sont des **fixtures synthétiques étiquetées comme telles**, générées pour exercer la logique de calcul (rejeu d'alarme, dérive, ajustement k·Qⁿ). Elles démontrent que le code calcule ce qu'il prétend calculer — elles ne démontrent **rien** sur la performance de la méthode ni sur le comportement d'un filtre réel.

Les données du protocole E0–E7 (voir `docs/05-validation-protocol.md`) seront déposées ici, avec leur contexte, lorsqu'elles existeront.
